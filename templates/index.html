Google Places Lead Finder

Searches Google's official Places API for a business type across the areas you list, then flags listings by review count and website presence. Uses your Google Cloud billing account — no scraping.

This calls Google's real API, so pricing applies beyond the free monthly allowance (currently 5,000 free searches + 1,000 free detail lookups/month). See README.md for current rates before running large searches. Note: Google's API does not expose claimed/unclaimed status, so that filter isn't available here.
